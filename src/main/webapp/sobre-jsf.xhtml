Sobre o Sistema

Este sistema web foi desenvolvido para auxiliar no gerenciamento de livros da Biblioteca da Universidade Cesumar com intuito educacional.

Funcionalidades

  • Cadastro de livros com título, autor, ano de publicação e ISBN.
  • Listagem dos livros cadastrados em uma tabela organizada.
  • Exclusão de livros pelo ID.
  • Validação de campos obrigatórios.
  • Validação simples de ISBN.

Tecnologias Utilizadas

  • Java
  • Servlet
  • JSP
  • JSF
  • Maven
  • Apache Tomcat
  • HTML
  • CSS
  • Git e GitHub
